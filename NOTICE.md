# Provenance and trademarks

## The whale mark

`fish-path.js` holds the DeepSeek whale logo path, extracted from DeepSeek
Harness's own UI assets by `tools/extract-fish-path.mjs`. It is included so the
splash screen can show the product's own mark while booting it — the plugin is a
skin for that product, and a different logo would make it a different thing.

The path is **not** covered by this project's MIT license; it remains DeepSeek's
asset. It is used here nominatively, to identify the application being skinned.
If you fork this plugin for another product, replace that file — the extractor
takes the source path as an argument, and `splashMarkup()` reads the viewBox and
path from it and nothing else.

## Generated files

These are committed so a fresh clone renders and tests without a build step.
Each one is regenerated by a script, and the script is the source of truth:

| File | Regenerate with |
|---|---|
| `fish-path.js` | `node tools/extract-fish-path.mjs <path-to-a-checkout>` |
| `icon.svg` | hand-drawn; edit directly |
| `preview.html` | `npm run preview` (gitignored — build it locally) |
